# Playbook: Launch WhatsApp Platform

## Overview
Deploy a WhatsApp-based automation platform or bot.

## Steps
1. **Webhook Setup**: Build endpoints with `skills/backend/api-endpoint-builder`.
2. **State Management**: Use `skills/automation/workflow-orchestration-patterns`.
3. **Agent Integration**: Connect `skills/ai-agents/ai-agent-development` for intelligent replies.
4. **Scaling**: Use `skills/backend/nodejs-best-practices` for high-concurrency handling.
5. **Security**: Audit with `skills/security/api-security-best-practices`.
