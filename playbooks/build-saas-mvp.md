# Playbook: Build SaaS MVP

## Overview
Accelerated workflow for building and launching a Software-as-a-Service Minimum Viable Product.

## Steps
1. **Architecture Design**: Use `skills/architecture/software-architecture` to plan the core system.
2. **Auth Integration**: Implement `skills/backend/auth-implementation-patterns` for rapid user management.
3. **Core Backend**: Build endpoints using `skills/backend/api-endpoint-builder`.
4. **Deployment**: Deploy using `skills/deployment/production-readiness-deployment`.
5. **Initial Testing**: Run `skills/testing/test-automator` to ensure basic functionality.
