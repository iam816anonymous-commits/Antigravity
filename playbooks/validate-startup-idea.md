# Playbook: Validate Startup Idea

## Overview
Systematic process to validate a startup idea using lean methodologies and AI-driven insights.

## Steps
1. **Define Hypothesis**: Use `skills/founder-os/ab-test-setup` to define clear, measurable hypotheses.
2. **AI Market Analysis**: Use `skills/founder-os/ai-product` to analyze market fit and competitor landscape.
3. **Build Landing Page MVP**: Rapidly deploy a landing page to test interest.
4. **Gather Feedback**: Use `skills/founder-os/ai-wrapper-product` to refine the value proposition based on early feedback.
5. **Analyze Results**: Review metrics and decide whether to pivot or persevere.
