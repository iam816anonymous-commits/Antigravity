# Playbook: Production Readiness Review

## Overview
Final checklist and process before moving a system to production.

## Steps
1. **Infrastructure Audit**: Use `skills/deployment/cloud-devops`.
2. **Performance Baseline**: Run stress tests.
3. **Security Sign-off**: Follow `playbooks/production-security-audit.md`.
4. **Monitoring Setup**: Configure alerts and logging.
5. **Final Review**: Use `skills/architecture/architect-review`.
