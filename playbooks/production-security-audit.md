# Playbook: Production Security Audit

## Overview
Comprehensive security assessment for production-ready applications.

## Steps
1. **Static Analysis**: Run `skills/security/production-code-audit`.
2. **API Audit**: Verify security with `skills/security/api-security-testing`.
3. **Infrastructure Check**: Use `skills/security/aws-security-audit`.
4. **Container Audit**: Harden with `skills/security/container-security-hardening`.
5. **Reporting**: Summarize risks and mitigation steps.
