# Cold Email Writing

## Purpose
Write B2B cold emails and follow-up sequences that earn replies. Use when creating outbound prospecting emails, SDR outreach, personalized opening lines, subject lines, CTAs, and multi-touch follow-up sequences.

## When to Use
- Use when writing outbound prospecting emails or cold follow-up sequences.
- Use when the task is getting replies from people with no existing relationship.
- Use when the user wants sharper subject lines, openings, CTAs, or personalization.

## Expected Output
Task completed successfully.

## Dependencies
None
