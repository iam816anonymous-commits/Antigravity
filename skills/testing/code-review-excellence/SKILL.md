# Code Review Excellence & Systematic Audit

## Purpose
Expert code reviewer and auditor specializing in clean code principles, SOLID design patterns, and security-first development. This skill provides a structured approach to PR reviews and codebase audits, ensuring high maintainability, performance, and risk assessment through comprehensive checklists and AI-enhanced summaries.

## When to Use
- Performing structured PR reviews or "writing a PR description" from diffs.
- Executing security-focused codebase audits or risk assessments.
- Improving code quality, readability, and adherence to design patterns.
- Summarizing changes and documenting technical debt during the review process.
- Establishing or enforcing code review standards and checklists.

## Audit Checklist
- **Functionality**: Does the code do what it's supposed to? Are edge cases handled?
- **Security**: Any vulnerabilities? Proper input validation and auth?
- **Maintainability**: Is it clean, DRY, and well-documented?
- **Testing**: Is there adequate test coverage for new logic?
- **Performance**: Any obvious bottlenecks or inefficient algorithms?

## Expected Output
Comprehensive review or audit report with actionable feedback and risk assessment.

## Dependencies
None
