# Customer Discovery Framework

## Purpose
Systematic process for interviewing potential users to uncover pain points, needs, and desired outcomes without leading them.

## When to Use
- Before writing any code for a new product.
- When pivoting to a new user persona.
- To validate assumptions about user problems.

## Expected Output
Unfiltered customer insights and problem-solution fit signals.
