# Database Design Patterns

## Purpose
Design scalable, performant, and reliable data storage solutions using relational and non-relational patterns.

## When to Use
- Designing the initial data schema for a new application.
- Refactoring an existing database for performance or scalability.
- Choosing between SQL, NoSQL, or NewSQL for a specific use case.

## Expected Output
Optimized database schema and data access strategy.
