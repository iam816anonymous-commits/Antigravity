# API Documentation & Developer Experience

## Purpose
Expert API documentation specialist focusing on creating world-class developer experiences. This skill covers the entire documentation workflow: generating OpenAPI 3.1+ specs, creating interactive developer guides, maintaining comprehensive documentation portals, and using AI-powered workflows to drive API adoption and reduce integration time.

## When to Use
- Creating or updating API documentation and OpenAPI specifications.
- Designing developer guides and adding high-quality code examples.
- Setting up or maintaining API portals and documentation infrastructure.
- Improving the overall developer experience (DX) for an API.
- Integrating AI into documentation maintenance workflows.

## Key Principles
- **Clarity First**: Documentation must be accurate, concise, and easy to navigate.
- **Interactive**: Support interactive "Try it now" features and sandbox environments.
- **Comprehensive**: Include authentication guides, error code references, and rate limit details.
- **Automation**: Use tools to keep documentation in sync with code changes.

## Expected Output
Task completed successfully with high-quality, developer-centric documentation.
